# Tonja 新时代通假字生成工具

把一段中文里的每个汉字，替换成**偏旁不同、主体相同的「形近字」**。整句话一眼扫过去仍能联想出原意。

注意，本项目与古代真实的通假字没有关系。

## 在线体验

部署在 GitHub Pages 上：把仓库的 Pages 指向主分支根目录即可访问。

## 它是怎么做到的

汉字大多是「合体字」，由一个**偏旁**（出现频率高、可替换）和一个**主体**（出现频率低、有辨识度）组成。本工具用 **IDS（表意文字描述序列）** 把每个汉字拆成结构部件（例如 `操 = ⿰扌喿`），找出最有辨识度的「主体」，再按优先级用三种方式找形近候选：

1. **包含**：原字能否被「添个偏旁」变成另一个字。例如 `我` 出现在 `俄（⿰亻我）`、`哦（⿰口我）` 里，于是 `我 → 俄 / 哦`；`早 → 章 / 草 / 卓`。原字被完整保留，肉眼一定认得出。
2. **同主体**：与原字共享同一主体、且主体处在**相同视觉位置**、外层结构也兼容的字。例如 `操（⿰扌喿）→ 懆（⿰忄喿）`。只在「包含」找不到候选时才用——能被整体包含的字（如 `早`）已被熟知，再拆成 `隼 / 夲` 反而降低识别。
3. **去偏旁兜底**：前两步都没有候选时，如果原字的主体本身就是个**读音完全相同**的真字，就直接去掉偏旁。例如 `莱（⿱艹来）→ 来`（都读 lái）、`痹（⿸疒畀）→ 畀`（都读 bì）。

转换时对每个字从它的候选里**随机**挑一个，所以多点几次「随机转换」结果会不一样。

结构约束很关键：同主体匹配要求外层结构相同，唯一例外是允许 `⿺ → ⿰`（为了 `逼（⿺辶畐）→ 福（⿰示畐）`）。这样既能跨过这一种结构，又能挡住 `早（⿱日十）→ 叶（⿰口十）` 这类破坏字形的跨结构替换。

## 项目结构

```
IDS-UCS-Basic.txt   原始数据：CJK 基本汉字（U+4E00–U+9FA5）的 IDS 拆字表
utils.py            可复用工具集：IDS 解析（结构树、部件提取、视觉位置）+ JSON / IDS 文件读写
build.py            本项目数据管线：拆字 → 生成 mapping.json
mapping.json        前端使用的映射表 { 原字: [候选字, ...] }
index.html          单页界面（内联 CSS）
app.js              前端逻辑：加载映射、随机替换、计数、复制、标题打字机
```

## 重新生成数据

需要 Python 3 与 `pypinyin`（去偏旁兜底要用拼音判断同音）：

```bash
pip install pypinyin

# 全流程：拆字 + 生成映射
python build.py

# 或单独运行某一阶段
python build.py --stage basic     # 仅生成 all_basic_hanzi.json（中间产物）
python build.py --stage mapping   # 仅由中间产物生成 mapping.json
```

可在 `build.py` 顶部调参：

- `MAX_CANDIDATES`：每个字最多保留多少个候选（控制 `mapping.json` 体积）。
- `MIN_BODY_LEN` / `TRIVIAL_BODIES`：过滤掉过于平凡、没有辨识度的「主体」。
- `ALLOWED_CROSS`：允许的跨结构方向（默认仅 `⿺ → ⿰`）。
